## 📦 pgxs – шардирование поверх pgx

pgxs — это легковесная библиотека для прозрачного шардирования PostgreSQL с использованием согласованного хеширования на основе фиксированного количества виртуальных бакетов (схем). Она предоставляет типобезопасный API с дженериками, поддерживает транзакции в рамках одного бакета, массовые операции через pgx.Batch, параллельные запросы по всем бакетам и автоматическую подстановку имени схемы ({schema}) в любом SQL-запросе.
